In this project, I was provided with the maze environment and supporting code for experience replay, while my implementation focused on training the neural network via reinforcement learning 
to approximate the most favorable action in any given circumstance. This process reflects how computer scientists approach problems by identifying an intended outcome, determining the necessary
components, and refining their implementation through testing. Such work allows for the development of systems capable of automating processes which may otherwise require extensive resources or 
manual effort. However, the implementation of these systems also introduces ethical responsibilities regarding reliability, security, and the potential consequences of incorrect decisions, 
particularly when considering their effects on end users and organizations; the first and foremost duty of a computer scientist is to provide security to the end user.
